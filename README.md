# Task-7-Customer-Segmentation-Using-Unsupervised-Learning
Customer Segmentation using K-Means Clustering with Exploratory Data Analysis (EDA), PCA visualization, and business-driven marketing strategies.

## Overview

This project applies **K-Means Clustering**, an unsupervised machine learning algorithm, to segment mall customers based on their annual income and spending behavior. Customer segmentation helps businesses identify different customer groups and develop personalized marketing strategies to improve customer satisfaction and maximize business revenue.

---

## Project Objective

- Perform Exploratory Data Analysis (EDA)
- Apply K-Means Clustering to segment customers
- Determine the optimal number of clusters using the Elbow Method
- Visualize customer segments using PCA
- Analyze customer groups
- Suggest marketing strategies for each customer segment

---

## Dataset

**Dataset:** Mall Customers Dataset

### Features

- CustomerID
- Gender
- Age
- Annual Income (k$)
- Spending Score (1–100)

## Results

- Successfully segmented customers into five distinct clusters.
- Identified customer groups with different spending behaviors.
- Visualized clusters using PCA.

- Demonstrated how customer segmentation supports data-driven marketing decisions.

---

## Business Insights

- High-income customers are not always high spenders.
- Premium customers should be retained using loyalty programs.
- Budget-conscious customers respond better to promotional offers.
- Personalized marketing can improve customer engagement and increase sales.
